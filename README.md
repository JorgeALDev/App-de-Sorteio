# LoL Champion Picker 🎮

[![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=for-the-badge&logo=kotlin&logoColor=white)](...)
[![Jetpack Compose](https://img.shields.io/badge/Jetpack%20Compose-4285F4?style=for-the-badge&logo=jetpackcompose&logoColor=white)](...)
[![Android](https://img.shields.io/badge/Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)](...)

App Android que sorteia 3 campeões aleatórios de League of Legends,
com ícones carregados em tempo real via Data Dragon API da Riot Games.

---

## Funcionalidades

- Sorteio de 3 campeões com um toque
- Ícones dos campeões via Data Dragon API (169 campeões)
- Tratamento de nomes especiais: apóstrofos, nomes compostos, caracteres especiais
- Fallback de imagem para campeões sem asset disponível
- Botão de reset para novo sorteio

---

## Stack

| Tecnologia | Uso |
|------------|-----|
| Kotlin | Linguagem principal |
| Jetpack Compose | UI declarativa |
| Coil | Carregamento assíncrono de imagens |
| Data Dragon API | Assets e dados dos campeões |
| Material Design 3 | Componentes e theming |
