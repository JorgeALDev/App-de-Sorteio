## 📖 Sobre o Projeto

Aplicativo Android simples que sorteia aleatoriamente um campeão de **League of Legends** a partir de uma lista pré-definida. Ideal para decidir qual campeão jogar ou criar desafios entre amigos.

## 🎓 Contexto Educacional

Este é meu **primeiro projeto em Kotlin**, desenvolvido acompanhando um [tutorial do YouTube](https://youtu.be/bvauaOmqSSs) sobre criação de apps de sorteio em Android.

> 💡 **Objetivo**: Dar os primeiros passos em Kotlin e desenvolvimento Android, aprendendo conceitos básicos de UI, lógica de programação e manipulação de listas.

**Personalização**: Substituí a lista de nomes do tutorial original por uma lista com todos os campeões de League of Legends para tornar o app mais interessante e com minha identidade.

## 🚀 Tecnologias Utilizadas

- **Kotlin** - Linguagem de programação

## 📱 Como Executar

### Pré-requisitos
- Android Studio instalado
- JDK 8 ou superior
- Dispositivo Android ou emulador

### Passos

1. Clone o repositório:
```bash
git clone https://github.com/JorgeALDevEntomoTrackFrontend/App-de-Sorteio.git
```

2. Abra o projeto no Android Studio:
```
File > Open > Selecione a pasta do projeto
```

3. Aguarde o Gradle sincronizar

4. Execute o app:
   - Conecte um dispositivo Android (com depuração USB ativada)
   - Ou inicie um emulador
   - Clique em **Run** (▶️) ou pressione `Shift + F10`
